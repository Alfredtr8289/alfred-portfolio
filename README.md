# Alfred T R Portfolio

A responsive, static portfolio site built with plain HTML, CSS, and JavaScript. No build step or package installation is needed.

## Preview

Open index.html in a modern browser.

## Publish

Upload the contents of this folder to any static web host, such as GitHub Pages, Netlify, or Cloudflare Pages. The site uses relative asset paths, so it also works from a subdirectory.

## Edit

- Update page content and links in index.html.
- Change layout, colors, and motion in styles.css.
- Change interactions in script.js.

The animations respect the browser's reduced-motion preference.
